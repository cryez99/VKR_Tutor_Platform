# VKR_Tutor_Platform
# Разработка информационной системы генерации индивидуальных заданий и мониторинга прогресса учеников для репетитора

## ФИО
Гридусов Павел Лаврович
## Группа
РИС-23-3
## Тема ВКР
Разработка информационной системы генерации индивидуальных заданий и мониторинга прогресса учеников для репетитора по математике и информатике (с интеграцией ИИ для проверки домашних заданий).

## Требования к программному продукту (Краткая постановка задачи)
Необходимо разработать веб-платформу для взаимодействия репетитора и учеников. Система должна объединять в себе функции мессенджера (переписка, отправка ссылок на уроки), менеджера домашних заданий и аналитического дашборда для отслеживания прогресса учеников. Ключевой особенностью является интеграция обученной ИИ-модели для автоматической проверки и оценки сданных домашних работ, что снижает временные затраты репетитора, а также эта же ИИ-модель будет являться чат-ботом, который может помочь ученику понять или лучше узнать какую-либо тему.
